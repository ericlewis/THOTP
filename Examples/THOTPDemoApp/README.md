# THOTP Demo App

A SwiftUI demo app showcasing the THOTP library features.

## Features

- **Live OTP Codes**: Displays various TOTP and HOTP configurations
- **Animated Countdowns**: Real-time countdown timers updating every 0.1 seconds
- **Color-Coded Progress**: Progress bars that transition from green → orange → red
- **Multiple Hash Algorithms**: SHA1, SHA256, SHA512 examples
- **Different Configurations**: Various digit counts, periods, and counter-based codes

## Running the App

1. Open `THOTPDemoApp.xcodeproj` in Xcode
2. Select a simulator or device
3. Build and run (⌘R)

The app will display a list of sample OTP codes with live countdowns and progress indicators.
